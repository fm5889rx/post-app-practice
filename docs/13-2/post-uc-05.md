#### UC-05: 投稿を編集する

- **アクター**: 投稿者
- **事前条件**: ログインユーザーが投稿していること
- **基本フロー**:
  1. 投稿者が編集ボタンを押す
  2. システムがログインユーザーが投稿者本人であるかを確認する
  3. 
  3. 投稿者が投稿本文を編集する
- **代替フロー**:
  - 2a. ログインユーザーが投稿者でない：403エラーで投稿一覧に戻る
  - 3a. 投稿タイトルが長すぎる：バリデーションエラーになる
  - 3b. 投稿トピックが指定されていない：バリデーションエラーになる
- **事後条件**: 新しい投稿本文に書き換わる
- **受け入れ条件**:
  - [x] 投稿一覧画面に編集ボタンが表示される
  - [x] 編集ボタンを押すと投稿本文が表示される
  - [x] 投稿本文を修正して保存できる
  - [x] 一覧画面に戻ると新しい投稿内容に変わる
